# Опросник связанности Розалинд Уоттс (Watts Connectedness Scale, WCS-19)

> **Методологическая справка:**  
> Валидированная шкала *Watts Connectedness Scale (WCS)* разработана д-ром Розалинд Уоттс и коллегами (Watts et al., 2022, *Psychopharmacology*, 239, 3461–3483, Imperial College London).  
> В отличие от шкал симптомов депрессии или тревоги, WCS измеряет **связанность (Connectedness)** — с собой, с другими людьми и с миром.  
> **Тайминг применения:**  
> 1. Базовый замер ($T_0$): на этапе подготовки (до сессии).  
> 2. Интеграционный замер ($T_1$): через 7–14 дней после сессии (в окне нейропластичности).  
> 3. Отсроченный замер ($T_2$, опционально): через 4–12 недель для оценки устойчивости изменений.

---

## Инструкция для участника
Пожалуйста, оцените, насколько каждое из следующих утверждений соответствует вашему состоянию **за последние две недели**.  
Используйте шкалу от **0 до 100%** (визуально-аналоговая шкала):
- **0%** — Совсем нет
- **50%** — Умеренно / Наполовину
- **100%** — Полностью / В высшей степени

Правильных ответов нет — ориентируйтесь на первое откликающееся ощущение.

## Подсчет баллов (для терапевта)

Пункты **1, 8, 12, 13** имеют обратный подсчет: перед расчетом среднего их значение пересчитывается по формуле `100 - балл`.

- **Связанность с собой (CTS):** среднее пунктов `2, 3, 4, 5, 6, 7` = `_____` % *(0–100)*
- **Связанность с другими (CTO):** среднее `((100-Q1) + (100-Q8) + Q9 + Q10 + (100-Q12) + (100-Q13)) / 6` = `_____` % *(0–100)*
- **Связанность с миром (CTW):** среднее пунктов `11, 14, 15, 16, 17, 18, 19` = `_____` % *(0–100)*
- **Общий балл связанности (Total WCS):** `(CTS + CTO + CTW) / 3` = `_____` % *(0–100)*

> *Примечание:* В оригинальной публикации Watts et al. (2022) не устанавливаются жесткие диагностические пороги (cut-offs). Основное клиническое значение имеет **динамика** ($T_0 \to T_1 \to T_2$) и сравнение трех субшкал между собой.

## Качественная рефлексия для интеграционной сессии
1. В какой из трех сфер (Я / Другие / Мир) разница между замерами «до» и «после» оказалась наиболее заметной?
2. Какие конкретные телесные или поведенческие привычки за последнюю неделю помогли поддержать это чувство связанности?
3. В каких жизненных ситуациях старый паттерн изоляции возвращается снова, и какая опора помогает вам в этот момент?
